Vice Once a Day Uploader

A private publishing tool for the TikTok account @viceonceaday

This page contains the Terms of Service and the Privacy Policy for the application Vice Once a Day Uploader, which is used to publish prepared video clips to the owner's own TikTok account.

What this tool does

Vice Once a Day Uploader is a private desktop tool used by one operator to upload edited video clips to the operator's own TikTok account. The clips are short gameplay highlights from live streams. The operator selects and prepares each clip before it is published.

Terms of Service

Last updated: 16 November 2026

  • The tool is not offered to the public. There are no user accounts, no sign-up and no third-party users.
  • Only the owner of the TikTok account @viceonceaday uses this application, and only to publish to that same account.
  • The operator is responsible for the content published with the tool.
  • Clips are published with credit to the original streamers. If a rights holder asks for a clip to be removed, it is removed within 24 hours.
  • The tool is provided as is, without warranty of any kind. Use is at the operator's own risk.
  • These terms may be updated at any time. The current version is always shown on this page.

Privacy Policy

Last updated: 16 November 2026

  • What is stored: two pieces of information on the operator's own computer: an access token that TikTok issues after login, and a list of the video files that have already been uploaded.
  • What is read from TikTok: only the basic profile information of the authenticated account (display name and avatar). This is used solely to confirm that the login worked and that the correct account is connected.
  • What is not collected: no personal data of other users, no contact lists, no device identifiers, no location data.
  • Sharing: no data is transmitted to third parties. No analytics and no tracking services are used.
  • Where data lives: everything stays on the operator's own computer. Nothing is stored on a server operated by this application.
  • Revoking access: the access token can be revoked at any time in the TikTok settings under Security and permissions. After revocation the tool can no longer publish anything.
  • Deleting data: deleting the token file and the upload list from the operator's computer removes all stored information completely.
